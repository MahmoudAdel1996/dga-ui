<Callout type="info">
  `sdga-ui` ships no JavaScript. The ring is driven entirely by the `--radial-stepper-progress`
  custom property (a number from `0` to `100`) set on the block — compute it in your app as
  `activeStep / totalSteps * 100`. The SVG markup is byte-identical at every size, so only the size
  modifier changes.
</Callout>

## Basic usage

A ring, a centred `N of M` counter, and an optional text column describing the current step.

  `aria-valuemax` on the block itself.
</Callout>

## Animating between steps

`stroke-dashoffset` transitions over `0.5s`, so simply updating the custom property animates the
ring. The transition is disabled under `prefers-reduced-motion: reduce`.

```js
const stepper = document.querySelector('.radial-stepper');
stepper.style.setProperty('--radial-stepper-progress', (activeStep / totalSteps) * 100);
```
