# Dropdowns

SDGA UI styles Bootstrap's dropdown component with the SDGA palette — matching states for
hover, pressed, focused, selected, and disabled items straight from the [Dropdown design
spec](https://design.dga.gov.sa/guidelines/components/actions/dropdown).

<Callout type="info">
  Dropdowns need Bootstrap's JS bundle (`bootstrap.bundle.min.js`) for the toggle behavior — SDGA
  UI ships styles only. Try hovering, clicking, and tabbing through the items below to see every
  state.
</Callout>

## Basic Dropdown

<Preview>
  <BasicDropdown />
</Preview>

```html
<div class="dropdown">
  <button class="btn btn-secondary dropdown-toggle" type="button" data-bs-toggle="dropdown" aria-expanded="false">
    Dropdown button
  </button>
  <ul class="dropdown-menu">
    <li><a class="dropdown-item" href="#">Action</a></li>
    <li><a class="dropdown-item" href="#">Another action</a></li>
    <li><a class="dropdown-item" href="#">Something else here</a></li>
  </ul>
</div>
```

## Selected Item

Add `.active` to the currently selected option — it gets a checkmark instead of a background fill.

<Preview>
  <SelectedDropdown />
</Preview>

```html
<ul class="dropdown-menu">
  <li><a class="dropdown-item active" href="#">Newest first</a></li>
  <li><a class="dropdown-item" href="#">Oldest first</a></li>
  <li><a class="dropdown-item" href="#">Most popular</a></li>
</ul>
```

## Disabled Items

Add `.disabled` and `aria-disabled="true"` to remove an item from interaction.

<Preview>
  <DisabledItemDropdown />
</Preview>

```html
<li><a class="dropdown-item disabled" aria-disabled="true">Archive</a></li>
```

## Grouped Items with Headers

Use `.dropdown-item-group` with a `.dropdown-header` to label a set of related options, and
`.dropdown-divider` to separate groups.

<Preview>
  <GroupedDropdown />
</Preview>

```html
<ul class="dropdown-menu">
  <li class="dropdown-item-group">
    <h6 class="dropdown-header">Group label</h6>
    <ul>
      <li><a class="dropdown-item active" href="#">Option</a></li>
      <li><a class="dropdown-item" href="#">Option</a></li>
    </ul>
  </li>
  <li><hr class="dropdown-divider" /></li>
  <li class="dropdown-item-group">
    <h6 class="dropdown-header">Group label</h6>
    <ul>
      <li><a class="dropdown-item" href="#">Option</a></li>
    </ul>
  </li>
</ul>
```

## Split Button Dropdown

Pair a default action button with a dedicated toggle using `.dropdown-toggle-split`.

<Preview>
  <SplitDropdown />
</Preview>

```html
<div class="btn-group">
  <button type="button" class="btn btn-primary">Action</button>
  <button type="button" class="btn btn-primary dropdown-toggle dropdown-toggle-split" data-bs-toggle="dropdown" aria-expanded="false">
    <span class="visually-hidden">Toggle Dropdown</span>
  </button>
  <ul class="dropdown-menu">
    <li><a class="dropdown-item" href="#">Duplicate</a></li>
    <li><a class="dropdown-item" href="#">Rename</a></li>
    <li><hr class="dropdown-divider" /></li>
    <li><a class="dropdown-item" href="#">Delete</a></li>
  </ul>
</div>
```

## Directions

Use `.dropup`, `.dropend`, or `.dropstart` in place of `.dropdown` to open the menu in a
different direction.

<Preview>
  <DirectionDropdowns />
</Preview>

```html
<div class="dropup">...</div>
<div class="dropend">...</div>
<div class="dropstart">...</div>
```
