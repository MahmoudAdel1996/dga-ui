SDGA UI provides styled form controls with multiple states and sizes, including checkboxes,
radios, selects, and various visual states.

- [Checkboxes](/docs/components/forms/checkboxes) — primary, neutral, disabled and read-only checkboxes.
- [Radios](/docs/components/forms/radios) — primary and disabled radio buttons.
- [Select](/docs/components/forms/select) — sizes and states for `.form-select`.
