**SDGA UI** is a Bootstrap 5.3 theme that applies the Saudi Digital Government Authority (SDGA) design system on top of standard Bootstrap. You keep everything you know about Bootstrap — classes, components, utilities — and get government-grade styling, full RTL support, and Arabic typography out of the box.

<Callout type="info">
  **Live Demo:** Explore all components in action at
  [mahmoudadel1996.github.io/dga-ui](https://mahmoudadel1996.github.io/dga-ui/)
</Callout>

## Why SDGA UI?

- 🏛️ **SDGA design system** — the official palette (SA Green, Gold, Lavender), typography, spacing, and radii mapped onto Bootstrap
- 🌍 **Built-in RTL support** — one CSS file handles both directions; no separate Bootstrap RTL import
- 🔤 **IBM Plex Sans Arabic** — self-hosted font files included, optimized for Arabic and English
- 🎨 **Full palette utilities** — every shade (`primary-100` … `primary-950`) generates Bootstrap utility classes
- ⚡ **Zero configuration** — pure CSS theme, no JavaScript of its own; works with any framework (React, Angular, Vue, plain HTML)
- 🧩 **100% Bootstrap compatible** — all standard Bootstrap markup just works

## Installation

### Package manager

<Tabs items={['npm', 'yarn', 'pnpm']}>
  <Tab value="npm">```bash npm install sdga-ui bootstrap bootstrap-icons ```</Tab>
  <Tab value="yarn">```bash yarn add sdga-ui bootstrap bootstrap-icons ```</Tab>
  <Tab value="pnpm">```bash pnpm add sdga-ui bootstrap bootstrap-icons ```</Tab>
</Tabs>

<Callout type="warn">
  `bootstrap` and `bootstrap-icons` are peer dependencies. The compiled CSS already contains all
  Bootstrap **styles** — you only need Bootstrap's JavaScript for interactive components (dropdowns,
  modals, toasts, …) and Bootstrap Icons for the icon font.
</Callout>

### CDN

No build step needed — link the compiled CSS directly:

```html
<!-- jsDelivr -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/sdga-ui@latest/css/dga-ui.css" />

<!-- unpkg -->
<link rel="stylesheet" href="https://unpkg.com/sdga-ui@latest/css/dga-ui.css" />
```

<Callout type="info">
  For production, pin a specific version instead of `@latest`, e.g. `sdga-ui@1.0.33`.
</Callout>

## Usage

### Option 1 — Compiled CSS (recommended)

Import the ready-to-use CSS. It **replaces** Bootstrap's CSS — don't import both.

```javascript
// In your app's entry point
import 'sdga-ui/css/dga-ui.css';
import 'bootstrap-icons/font/bootstrap-icons.css';
import 'bootstrap/dist/js/bootstrap.bundle.min.js'; // for interactive components
```

Or in plain HTML:

```html
<!DOCTYPE html>
<html lang="ar" dir="rtl">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>My SDGA Application</title>
    <link rel="stylesheet" href="node_modules/sdga-ui/css/dga-ui.css" />
    <link rel="stylesheet" href="node_modules/bootstrap-icons/font/bootstrap-icons.css" />
  </head>
  <body>
    <div class="container mt-5">
      <h1>مرحباً بك</h1>
      <button class="btn btn-primary">ابدأ الآن</button>
    </div>
    <script src="node_modules/bootstrap/dist/js/bootstrap.bundle.min.js"></script>
  </body>
</html>
```

### Option 2 — SCSS source

For deeper customization, compile the theme yourself and override variables first:

```scss
// custom.scss

// Optional: override any Bootstrap/SDGA variable before importing
$primary: #0d47a1;
$border-radius: 8px;

// Import the full theme (fonts + variables + Bootstrap + customizations)
@import 'sdga-ui/theme/dga-ui';

// Your custom styles here
```

## RTL Support

RTL is built in — the same CSS file serves both directions. Just set the `dir` attribute:

```html
<!-- Arabic / RTL -->
<html dir="rtl" lang="ar">
  <!-- English / LTR -->
  <html dir="ltr" lang="en"></html>
</html>
```

<Callout type="success">
  Unlike stock Bootstrap, there is **no separate RTL stylesheet** to manage. Switching `dir` is all
  it takes.
</Callout>

## Your First Component

Standard Bootstrap markup, SDGA styling:

```html
<div class="container my-5">
  <div class="card">
    <div class="card-header">
      <h5 class="card-title mb-0">بطاقة معلومات</h5>
    </div>
    <div class="card-body">
      <p class="card-text">هذا مثال على بطاقة معلومات باستخدام نظام SDGA UI</p>
      <button class="btn btn-primary">اقرأ المزيد</button>
      <button class="btn btn-outline-secondary ms-2">إلغاء</button>
    </div>
  </div>
</div>
```

## Color System

The SDGA palette maps onto Bootstrap's semantic colors — `$primary` is SA Green 600 — and every shade is exposed as a utility class:

```html
<div class="bg-primary-100 text-primary-900 p-3">Light green surface</div>
<span class="badge bg-primary-600">SA Green</span>
<p class="text-primary-950">Darkest shade</p>
```

Available families: **Primary (SA Green)**, **Gold**, **Lavender**, **Success**, **Warning**, **Error**, **Info**, and **Neutral** — each in shades 25/50/100–950.

## Customization

Override any Bootstrap or SDGA variable before importing the SCSS theme:

```scss
$primary: #1a73e8;
$font-family-base: 'Your Font', 'IBM Plex Sans Arabic', sans-serif;
$border-radius: 8px;

@import 'sdga-ui/theme/dga-ui';
```

The theme source is organized in three layers:

| Layer                   | Purpose                                                    |
| ----------------------- | ---------------------------------------------------------- |
| `theme/config/`         | Foundations — colors, typography, spacing, radius, effects |
| `theme/components/`     | Bootstrap variable overrides per component                 |
| `theme/customizations/` | Post-Bootstrap utilities, SDGA-specific classes, RTL fixes |

## What's in the Package

```
sdga-ui/
├── css/
│   └── dga-ui.css             # Compiled CSS — ready to use
├── fonts/                     # IBM Plex Sans Arabic (self-hosted)
└── theme/
    ├── dga-ui.scss            # SCSS entry point
    ├── _variables.scss
    ├── config/                # Foundational variables
    ├── components/            # Per-component Bootstrap overrides
    └── customizations/        # Post-Bootstrap additions
```
