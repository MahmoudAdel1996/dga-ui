# Security Policy

## Supported Versions

Only the latest published version of `sdga-ui` on npm receives security fixes.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it
privately rather than opening a public issue.

- **Preferred**: use [GitHub Security Advisories](https://github.com/MahmoudAdel1996/dga-ui/security/advisories/new)
  to report it directly on this repository.
- **Alternative**: email mahmoooud.adel@gmail.com with details of the issue.

Please include as much of the following as possible:

- A description of the vulnerability and its potential impact
- Steps to reproduce or a proof of concept
- The affected version(s) of `sdga-ui`

## What to Expect

- We aim to acknowledge reports within 5 business days.
- We will investigate, work on a fix, and keep you updated on progress.
- Once a fix is released, we will credit the reporter (if desired) in the
  release notes, unless anonymity is requested.

Please do not disclose the vulnerability publicly until a fix has been
released.
